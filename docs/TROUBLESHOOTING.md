# Troubleshooting

| Symptom | Likely cause → fix |
|---|---|
| **500 / blank page** | Wrong PHP version or missing extension → run `/check.php`; read `storage/logs/php-error.log` and `storage/logs/app.log` (the error page shows a reference code that appears in `app.log`). |
| **"Application files not found"** | `public/` is not next to `app/`. Copy `public/app-path.php.example` → `app-path.php` and set the absolute app folder. |
| **404 on every page except `/`** | `mod_rewrite`/`.htaccess` not applied. Confirm `public/.htaccess` uploaded (hidden file: enable *Show Hidden Files* in File Manager) and `AllowOverride` is on (default on Bluehost). |
| **Page works but links/assets 404 in a sub-directory** | Set the doc root/layout per guide; if auto-detection is wrong add `'base_path' => '/grc'` under `'app'` in `config.php`. |
| **Setup page: "token file could not be created"** | `storage/` not writable → fix permissions, or create `storage/setup-token.txt` with any random 32 characters. |
| **Setup: cannot connect (error 1045/2002/1049)** | 1045 wrong user/password; 1049 wrong DB name; 2002 wrong host. Names include the cPanel prefix (`CPUSER_…`). The user must be *added to the database* with privileges. |
| **Setup shows config text instead of saving** | Neither `../grc-config/` nor `config/` is writable. Create the file manually at the shown path (mode 600) and press Continue. |
| **"Setup complete" but I need setup again** | Setup is closed on purpose. To reinstall: empty the database, delete `storage/installed.lock` and the `grc-config/config.php`. |
| **Locked out (throttle)** | Wait 15 minutes, or an administrator resets the password. Emergency: in phpMyAdmin `DELETE FROM login_attempts;` and reset `password_hash` with a hash generated by `php -r 'echo password_hash("NewPass123456", PASSWORD_DEFAULT);'`. |
| **Forgot the only administrator password** | Generate a hash as above, then `UPDATE users SET password_hash='…', must_change_password=1 WHERE username='admin';` in phpMyAdmin. |
| **Arabic shows as ???? in the database/CSV** | DB/tables must be `utf8mb4`; import `install.sql` (it sets `utf8mb4`). CSV includes a UTF-8 BOM — in Excel use *Data → From Text/CSV → UTF-8* if double-clicking fails. |
| **CSV opens as one column in Excel** | Regional list separator is `;` → use the *CSV (;)* button. |
| **Upload rejected** | Allowed: pdf, png, jpg, txt, docx, xlsx, ≤ 5 MB, content must match the extension. Also check `upload_max_filesize`/`post_max_size` (System status). |
| **"Your session expired / 419"** | Form left open > 30 min, cookies blocked, or the site is reached over both http and https. Reload the page and retry. |
| **Redirect loop after enabling HTTPS** | Behind a proxy that terminates TLS: add `'trust_proxy' => true` under `'app'`; or disable `force_https` until AutoSSL is valid. |
| **Migration fails halfway** | Restore the pre-upgrade backup; MySQL DDL cannot roll back. Fix the cause (usually privileges: the DB user needs CREATE/ALTER/INDEX/REFERENCES). |
| **Dates/times off by hours** | `'timezone'` in `config.php` (default `Africa/Tripoli`). |
| **Charts empty** | Charts only show stored data; there are no placeholder figures. Create risks/incidents or load demo data on a test database. |
